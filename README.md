# SOLUTION X — CampusConnect Landing Page

## Project
BSE2201 Software Engineering Foundations group assignment.

## Proposed problem
Important school announcements, deadlines and timetable/room changes can be scattered across different communication channels. This can make it harder for students to find current information.

## Proposed system
CampusConnect is a proposed central school communication platform where approved notices, deadlines and important updates can be organized in one place.

**Important:** The assignment requires the landing page only. A working CampusConnect system or interactive prototype is not required.

## Files
- `index.html` — landing page
- `styles.css` — responsive styling
- `script.js` — mobile navigation
- `project_plan.pdf` — simple project plan, Jira/GitHub workflow and presentation checklist
